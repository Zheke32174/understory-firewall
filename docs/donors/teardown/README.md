# Donor teardowns — how these apps actually look

Generated by `tools/donor-assets/teardown.sh` from real release APKs. **Read
these instead of describing a donor from memory.** Writing a spec from knowledge
of what an app *does* was the root cause of every failed round of this campaign:
it produces plausible menus with the wrong items, in the wrong order, under the
wrong headings, with the wrong wording.

There is no KVM in this sandbox, so the apps cannot be run. This is the faithful
substitute — an APK carries its own appearance.

Per donor:

| File | What it is |
|---|---|
| `menu.txt` | every menu resource, items in order, with real titles and `showAsAction` |
| `xml.txt` | preference screens: categories, rows, keys, summaries, `dependency` chains |
| `strings.txt` | the exact wording, resolved from the string table |

`layout.txt` (the raw view hierarchies) is produced by the tool but not committed
— it is large and mostly framework noise. Regenerate it when a specific screen's
structure matters.

## Worked example — why this matters

The spec written from memory said:

> Shelter/Island-style containment — managed profile creation and lifecycle.

Shelter, actually:

- Bottom nav is **two** tabs: `Main` | `Shelter`.
- Overflow: Search, Batch Freeze, Settings, Create Batch Freeze Shortcut,
  Install APK into Shelter, Open Documents UI, Show All Apps (checkable).
- Settings, three categories:
  - **Interaction** — File Shuttle, Block Contacts Searching, Payment Service Stub
  - **Services** — Auto Freeze Service, Auto Freeze Delay (*depends on* Auto
    Freeze Service), Skip Foreground Apps
  - **About** — Version, Source Code, Translate, Bug Report / Issue Tracker, Patreon

Same for InviZible: six preference screens (`common`, `dnscrypt`, `fast`,
`firewall`, `i2pd`, `tor`), and `fast` alone is Autostart (DNSCrypt / Tor / I2P /
Delay), DNSCrypt servers (Select DNSCrypt servers, Prevent DNS leaks), Tor
Settings (Route All traffic through Tor, Select sites, Select applications,
Exclude sites, Refresh interval, Exclude applications).

None of that specificity survives being recalled rather than read.
